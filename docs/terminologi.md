# Terminologi

| Begrepp | Definition | Första kapitel |
|---|---|---|
| AI-assistent | En AI som är utformad för att hjälpa till med en återkommande uppgift eller roll. | 1 |
| GPT | En anpassad assistent i ChatGPT med egna instruktioner och ibland kunskapsfiler eller särskilda funktioner. | 1 |
| Arbetsflöde | En ordnad serie steg som leder från behov till resultat. | 1 |
| GPT Builder | Verktyget i ChatGPT där användaren skapar och ändrar en egen GPT. | 2 |
| Instruktion | Text som styr hur en AI-assistent ska bete sig, svara och avgränsa sitt arbete. | 2 |
| Startfråga | Ett färdigt frågeförslag som hjälper användaren komma igång med en GPT. | 2 |
| Kunskapsfil | En fil som används som extra underlag för en assistent. | 4 |
| Källmaterial | Den information som används som underlag för ett svar, till exempel en fil, en webbsida eller användarens egen beskrivning. | 4 |
| Kontext | Relevant bakgrundsinformation som hjälper assistenten förstå och lösa uppgiften. | 4 |
| Jämförelsekriterier | Egenskaper eller frågor som används för att jämföra produkter, tjänster eller verktyg. | 5 |
| Beslutstabell | En tabell som strukturerar alternativ, kriterier, bedömningar och osäkerheter. | 5 |
| Osäkerhet | Sådant som inte går att avgöra säkert från tillgängligt underlag och därför bör markeras eller verifieras. | 5 |
| Project | En arbetsyta i ChatGPT som kan samla chattar, filer och kontext kring ett större arbete. | 6 |
| Custom Instructions | Personliga instruktioner som påverkar hur ChatGPT svarar generellt. | 6 |
| Tillfällig chatt | En vanlig chatt som används för en snabb eller engångsbaserad uppgift. | 6 |
| Specialisering | Att avgränsa en assistent till en tydlig återkommande uppgift eller roll. | 7 |
| Rollgräns | Beskrivning av vad en assistent ska göra, inte ska göra, behöver som underlag och lämnar ifrån sig. | 7 |
| Återanvändbar mall | En instruktion- eller strukturmall som kan användas när flera liknande assistenter skapas. | 7 |
| AI-agent | Ett AI-baserat system som kan följa mål, använda verktyg och utföra steg mer självständigt än en vanlig chatt. | 10 |
| Trigger | En händelse, tidpunkt eller förändring som startar ett arbetsflöde. | 10 |
| Automation | Ett regelstyrt eller händelsestyrt flöde där verktyg utför steg automatiskt. | 10 |

| Systeminstruktion | Den övergripande instruktion som beskriver hur en GPT ska fungera och agera. | 3 |
| Beteenderegler | Konkreta regler för vad assistenten ska göra, undvika eller prioritera. | 3 |
| Outputformat | Den struktur som assistentens svar ska följa, till exempel tabell, rapportmall eller punktlista. | 3 |
| Testfall | En planerad uppgift som används för att kontrollera hur en assistent beter sig. | 8 |
| Utvärderingskriterium | En egenskap som används för att bedöma kvaliteten i ett svar, till exempel relevans, tydlighet eller källkritik. | 8 |
| Iterationslogg | En enkel ändringslogg som visar vilket problem som upptäcktes, vad som ändrades och vilket resultat ändringen gav. | 8 |

| Designmönster | Ett återkommande sätt att lösa ett vanligt designproblem i en GPT eller ett AI-arbetsflöde. | 9 |
| Anti-pattern | Ett vanligt arbetssätt som verkar hjälpsamt men ofta skapar problem längre fram. | 9 |
| Felsökningsfråga | En enkel fråga som hjälper användaren hitta varför en assistent svarar dåligt eller beter sig otydligt. | 9 |

| Pipeline | Ett arbetsflöde där resultatet från ett steg används som input i nästa steg. | 11 |
| Handoff | En tydlig överlämning mellan steg eller assistenter, med underlag, syfte, osäkerheter och nästa uppgift. | 11 |
| Kvalitetskontroll | Ett separat granskningssteg där resultatet kontrolleras innan det används vidare. | 11 |

| AI-system | En organiserad samling assistenter, instruktioner, mallar, kunskapsfiler och rutiner som stödjer återkommande arbete. | 12 |
| Systemkarta | En enkel översikt som visar systemets delar, syfte, input och output. | 12 |
| Underhållsrutin | Ett återkommande sätt att testa, förbättra och dokumentera assistenter över tid. | 12 |

| Utvecklingslogg | Enkel dokumentation över ändringar, problem och testresultat när en assistent förbättras. |
| Förbättringsbacklogg | Prioriterad lista över möjliga förbättringar som kan väljas, skjutas upp eller tas bort. |
| Beslutsregel | Enkel regel som hjälper användaren välja rätt arbetssätt, till exempel vanlig chatt, Project, GPT eller automation. |
