# Övningar till kapitel 5: Produktjämförelser med AI-Analytikern

## Övning 1: Skapa jämförelsekriterier

Välj tre produkter, tjänster eller verktyg som kan jämföras med öppen information.

Fyll i:

```text
Alternativ A:
Alternativ B:
Alternativ C:

Målgrupp:
Användningsfall:

Måste finnas:
1.
2.
3.

Viktiga kriterier:
1.
2.
3.

Bonus:
1.
2.
```

## Övning 2: Skapa en tom beslutstabell

Be AI-Analytikern skapa en beslutstabell med följande kolumner:

- kriterium
- alternativ A
- alternativ B
- alternativ C
- kommentar/osäkerhet

Kontrollera att tabellen inte blandar fakta och gissningar.

## Övning 3: Testa följdfrågor

Använd denna prompt:

```text
Jag vill jämföra tre verktyg för omvärldsbevakning. Hjälp mig göra jämförelsen på ett strukturerat sätt.
```

Bra beteende:
- assistenten frågar efter målgrupp
- assistenten frågar efter användningsfall
- assistenten frågar efter kriterier
- assistenten markerar osäkerheter

Mindre bra beteende:
- assistenten börjar jämföra direkt utan underlag
- assistenten utser en vinnare utan kriterier
- assistenten nämner priser eller funktioner utan att markera att de måste kontrolleras

## Övning 4: Spara en återanvändbar mall

Skapa en kort mall för produktjämförelser och spara den som en textfil. Den kan senare användas som kunskapsfil i AI-Analytikern.
