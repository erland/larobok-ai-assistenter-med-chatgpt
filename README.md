# Bygg AI-assistenter med ChatGPT

Projekt för läroboken **Bygg AI-assistenter med ChatGPT** av **Erland Lindmark**.

## Innehåll
- `docs/` innehåller bokspecifikation, kapitelplan, canon, terminologi, status och exportmetadata.
- `chapters/` innehåller inledning och kapitel.
- `exercises/` innehåller separata övningsfiler när de behövs.
- `assets/cover/` är plats för genererad omslagsbild.
- `assets/image-prompts/` innehåller bildpromptar.
- `exports/` är plats för framtida EPUB/PDF/DOCX/Markdown-exporter.

## Nuvarande status
Projektet innehåller nu inledning och kapitel 1–11.
